About the Project

Food Ordering Behaviour and Consumer Trends Analysis

Project Overview

The Food Ordering Behaviour and Consumer Trends Analysis project explores food ordering patterns across multiple cities using interactive visualizations. Developed with Tableau Public and integrated into a Flask web application, it provides insights into customer preferences, cuisine demand, delivery performance, revenue trends, and meal ordering behavior. The dashboard enables restaurants and food delivery businesses to make data-driven decisions through clear and interactive business intelligence reports.

Project Highlights
  • Interactive Tableau Dashboard
  • Customer Behaviour Analysis
  • Cuisine Preference Analysis
  • City-wise Order Trends
  • Revenue Analysis
  • Delivery Performance Analysis
  • Customer Rating Insights
  • Interactive Tableau Story
